# KOX OS

KOX OS is a lightweight, independently developed Linux desktop platform built on Artix Linux (OpenRC) and Hyprland. Designed as a faster, more modular alternative to other distros, KOX OS strips away monolithic shells and systemd dependencies in favor of a bespoke, component-driven architecture: a Lua-scripted Hyprland session, a floating island bar, interactive GTK system panels, and a proprietary **kox-scale** engine that delivers instant, fluid UI scaling with absolutely zero compositor lag.

## Highlights

- **Lua-configured Hyprland** — the entire session is scripted in Lua (`.config/hypr/*.lua`): autostart, keybinds, input, looks, monitors.
- **Quickshell lockscreen** — a real `WlSessionLock` screen with PAM authentication (user-owned policy, no root edits), fluid choreography (desktop veil fade → staggered clock/date/pill bloom → collapse on unlock), an auto-focused password field (no click to type), an `flock` double-press guard, and a `hyprlock` fallback. Test it safely without touching the session: `KOX_LOCK_DRY=1 quickshell -p ~/.config/quickshell/lock.qml`.
- **Nothing-style clock** — the lockscreen clock uses the classic Nothing dot-matrix face (Ndot 57). The fonts are proprietary community rips: install them user-level at `~/.local/share/fonts/` and never commit them.
- **kox-scale engine** — one integer (9–20) scales every text surface: Waybar, the GTK panels, kitty, fuzzel, mako and generic GTK apps, each through its own warm-reload path (CSS hot-swap, live kitty socket, gsettings) with zero compositor interaction. App text carries readability floors, and `kox-scale apply` re-applies the stored scale at every boot as a byte-level no-op.
- **Boot reliability** — every session component starts through a guarded one-shot: the bar waits for the Wayland socket and retries bounded (`kox-waybar-autostart`), the scale self-heals, and the Bluetooth watcher publishes a lockstep state file that both bar widgets read, so the clock notch never moves.
- **Power profiles under OpenRC** — `power-profiles-daemon` via the official OpenRC init script (dbus activation is intentionally inert on Artix), switchable from the battery panel's profile pills.
- **Event-driven volume OSD** — a minimal thin overlay that appears only when volume or mute *actually* changes (immune to play/pause sink noise) and on Bluetooth audio handover.

## Layout

```
KOX-OS/
├── .bash_profile
├── .config/
│   ├── fuzzel/                 launcher + power menu
│   ├── hypr/                   Lua session: autostart, bindings, input, looks, monitors, hyprlock
│   ├── kitty/                  terminal (font_size owned by kox-scale)
│   ├── kox-panel/              panel scale.css (generated by kox-scale)
│   ├── mako/                   notifications
│   ├── quickshell/             lockscreen: lock.qml, test.qml, pam/lock.conf
│   ├── waybar/                 island bar: config.jsonc, style.css, theme-scale.css
│   └── wireplumber/            Bluetooth audio policy
├── .local/bin/
│   ├── kox-lock                session lock wrapper (flock guard, hyprlock fallback)
│   ├── kox-osd                 volume OSD (event-driven, level-diffed)
│   ├── kox-panel               GTK system panels (wifi / bluetooth / battery daemon)
│   ├── kox-panel-autostart     guarded panel daemon start
│   ├── kox-pulse-autostart     pipewire-pulse guard
│   ├── kox-scale               UI scale engine
│   ├── kox-waybar-autostart    guarded bar start (socket wait + bounded retries)
│   ├── kox-bt-watcher          shim → kox/kox-bt-watcher (BT lockstep daemon)
│   └── kox/                    widget scripts: bluetooth, bt-watcher, power, wifi
└── LICENSE
```

## Usage

| Action | Binding / command |
| --- | --- |
| Lock the session | `SUPER+CTRL+L` → `kox-lock` |
| Change UI scale | `kox-scale <9-20>` (also `current`, `reset`, `apply`) |
| Open a system panel | click the matching bar widget |
| Switch power profile | battery panel → power profile pills |
| Dry-run the lockscreen | `KOX_LOCK_DRY=1 quickshell -p ~/.config/quickshell/lock.qml` |
